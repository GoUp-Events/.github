<h2 align="center">&#9679; Sobre o projeto</h2>

<p align="center">
O <b>GoUp</b> é uma plataforma web de descoberta de eventos, com foco inicial em <b>Blumenau - SC</b>.<br>
Você busca eventos por cidade e filtros, vê o local no mapa, salva os favoritos<br>
e ainda recebe sugestões de uma IA: basta contar o que você quer fazer e quanto quer gastar.
</p>

<p align="center">
<b>&#9670; Descoberta</b> de eventos por cidade, categoria, data e preço &nbsp;&nbsp;
<b>&#9670; Mapa</b> com os locais via Google Places &nbsp;&nbsp;
<b>&#9670; Descoberta Mágica</b> com IA (Gemini) &nbsp;&nbsp;
<b>&#9670; Planos</b> Free e Premium
</p>
